# Sprint_4
## Спринт 4, Юнит-тестрование
### Список реализованных тестов
* Тест добавления книг в словарь
* Тест установления жанра для книги
* Тест получения жанра книги по её названию
* Тест вывода книг по определенному жанру 
* Тест получения словаря книга:жанр
* Тест книги подходящие детям по жанру попадают в список книг для детей
* Тест книги не подходящие детям по жанру не попадают в список книг для детей 
* Тест добавления книг в Избранное
* Тест удаления книг из избранного
* Тест получения списка избранного
